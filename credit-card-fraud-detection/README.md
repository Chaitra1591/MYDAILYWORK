# Credit Card Fraud Detection

## Overview
This project builds a Machine Learning model to detect fraudulent credit card transactions.  
The model analyzes transaction data and predicts whether a transaction is **fraudulent or legitimate**.

Fraud detection is an important application of machine learning used by banks and financial institutions to prevent financial losses.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

---

## Dataset
The dataset contains credit card transaction details.  
Each transaction is labeled as:

- **0 → Legitimate Transaction**
- **1 → Fraudulent Transaction**

The dataset was cleaned and preprocessed before training the model.

---

## Project Workflow
1. Load the dataset
2. Explore the dataset
3. Handle missing values
4. Convert categorical variables to numeric
5. Split dataset into training and testing data
6. Train the Machine Learning model
7. Predict fraud transactions
8. Evaluate model performance

---

## Machine Learning Model
The project uses **Logistic Regression** for classification.

The model learns patterns from historical transaction data and predicts whether a transaction is fraudulent.

---

## Model Evaluation
The model performance is evaluated using:

- Accuracy Score
- Classification Report
- Precision
- Recall
- F1 Score

---

## How to Run the Project
1. Open the notebook in **Google Colab**
2. Upload the dataset
3. Run all cells in the notebook
4. The model will train and display predictions and accuracy
